## Highlights

- Reviews now use the attached change bundle by default, so Pro-Gate does not request GitHub connector delivery unless you opt in.
- You can enable connector-capable review delivery once in your configuration when that matches your browser trust boundary.
- Existing review recovery, status, and harvest commands remain available regardless of this delivery setting.

## Upgrade

Update the plugin and runtime together to v0.38.0. No migration is needed; set `PRO_GATE_INPUT_POLICY=connector-enabled` only when you intentionally want connector-capable delivery.

## Details

The default bundle-only policy controls Pro-Gate's own review request. It cannot attest to or revoke pre-existing ChatGPT browser connector grants or connector-bound project permissions; those remain an operator trust boundary.
