# v0.60.1

## Highlights

- A follow-up review now rechecks every earlier minor finding as well as the major ones, so a minor defect left unfixed can no longer drop out of the next review unnoticed.

## Upgrade

Update the plugin and runtime together to v0.60.1. Nothing else to do. Rolling back to v0.60.0 is safe; only the review prompt changed.

## Details

A confirming pass (`--confirm <prior-review-file>`) attaches the previous review and asks the reviewer to account for each earlier finding before it reports new ones. Until now that accounting covered only P0 and P1 findings, and the pass then asked for "genuinely new" findings. A caller that also fixes P2 findings could leave one unfixed, and the next pass was neither required to recheck it nor expected to report it as new.

The confirming pass now requires every prior P0, P1 and P2 finding to be listed as RESOLVED, with the file:line of the fix, or STILL-PRESENT, reported again as a finding. Prior P3 nits are still not rechecked.

The round governor still scores only open P0 and P1 findings, so round grants and the churn stop are unchanged. The pass still reviews the full current diff, and the output format, verdicts and input modes are unchanged.

## Fixed

- A confirming pass did not recheck prior P2 findings, so one left unfixed could drop out of the review.
