## Highlights

- Fixed a case where an old review could hold one of your review slots indefinitely, even after its pull request was merged or moved on.
- Recovering such a review now releases the slot instead of reporting that it is still working.
- Reviews whose ownership cannot be proven are still left alone, exactly as before.

## Upgrade

Update the plugin and runtime together to v0.38.1. No migration or state deletion is needed; run exact recovery for an affected marker after upgrading.

## Details

Marker mint time is no longer treated as independent charge evidence because a review can wait in the queue between marker creation and charge recording. GitHub must still prove that the bound pull request was merged, closed, or moved to a different head. Supersession retains the original charge, marker, conversation URL, and optional audit harvest while releasing current-head ownership and account capacity; it never dispatches another review or refunds the charged round.
