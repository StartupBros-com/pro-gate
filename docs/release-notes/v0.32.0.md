## Highlights

- Review conversations now receive the exact pull request and round name, making every run easy to identify in ChatGPT.
- Saved reviews archive automatically, while unfinished reviews stay visible and verified pre-browser failures can retry without consuming a round.
- Browser cleanup verifies ownership before changing anything; incomplete logging and uncertain sends stay charged to prevent duplicates.

## Upgrade

Nothing to do — the next review picks up the new conversation lifecycle automatically.

## What this means in practice

Review chats no longer depend on ChatGPT's best-effort automatic title, and completed chats no
longer pile up in the sidebar. pro-gate applies the exact run name through the visible ChatGPT
controls, then archives only after the review has been validated and saved in durable,
run-addressed storage.

Anything unfinished, failed, ambiguous, or associated with another run remains untouched and
available to inspect or harvest. A browser UI change can skip organization, but it cannot change
the review result or turn a recoverable run into a completed one.
