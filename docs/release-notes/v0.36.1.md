## Highlights

- Completed reviews no longer get mistaken for unfinished work and block a valid new review.
- Reviews that truly stopped before producing a complete result still recover safely without spending another Pro slot.

## Upgrade

Nothing to do — the next review picks it up automatically after the plugin and runtime update to v0.36.1.

## Details

Pro-gate keeps recovery metadata after every charged review so interrupted work can be found without spending again. Version 0.36.0 could mistake that permanent history for unfinished work even after the same review had already produced a complete durable result.

Version 0.36.1 distinguishes a completed run from an unresolved one without reusing the old result for current code or evidence. If another charged run is genuinely unresolved, recovery still takes priority and no new review starts.
