## Highlights

- Reviews that are making real progress now earn extra rounds automatically, so a pull request that is genuinely converging no longer gets cut off mid-way.
- Reviews going in circles now stop early instead of quietly burning your remaining review quota on repeated passes that are not improving anything.
- A review that fails before it ever reaches the model no longer counts against your quota.

## Upgrade

Nothing to do. The next review you run picks all of this up automatically.

## What this means in practice

pro-gate limits how many times a single pull request can be re-reviewed in a day, so one
noisy change cannot starve everything else in your queue. That limit used to be a flat
count, which was wrong in both directions: genuinely improving reviews hit the wall and
needed a manual override, while reviews stuck in a loop were allowed to spend the full
budget anyway.

The limit now watches whether each pass is actually reducing the number of open findings.
Shrinking earns more rounds, up to a hard ceiling that never moves. Two passes in a row
that fail to shrink stop the loop early and hand the remaining findings to you, along with
the trajectory that led to the decision, so you can see at a glance whether a change was
converging or churning.
