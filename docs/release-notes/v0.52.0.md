# v0.52.0

## Highlights

- Reviews no longer leave a ChatGPT tab open for every superseded round, so the review browser stops growing until it runs the machine out of memory.
- A rate-limit message left behind on an old tab can no longer restart the cooldown timer over and over, which was stalling new reviews for hours.
- Waits for a review slot or lock now always end on schedule instead of spinning forever when a lock or guard cannot be acquired.

## Upgrade

Nothing to do — the next review picks it up automatically.

Tabs that leaked before this release are not closed retroactively. If the review browser is
already large, restart it once (or close the old conversation tabs by hand) and it stays small
from then on.

## Details

Eight fixes across ten commits, each with a regression test that fails on the previous release:

- `--recover` now closes the run's own ChatGPT tab on both supersession exits (already
  superseded, and freshly proven superseded by a merged/closed PR or a moved head). Fresh runs
  and harvests already closed their tab on success; the supersession path never did, and the
  daemon takes that path once per superseded round. Tabs of runs that stall or fail without ever
  being superseded are still left open; that residual is tracked on the issue.
  `PRO_GATE_KEEP_TABS=1` still suppresses the close. Refs #206.
- A rate-limit modal or interstitial seen on a tab this run does not own is charged to the
  account cooldown once per batch of new sightings. A repeat sighting of the same tab with the
  same text is ignored and named on stderr instead of rewriting the cooldown file, so a caller
  that waits out `seconds_remaining` is no longer re-armed by the same abandoned tab. A modal
  over the run's own conversation still re-arms every time. Ignoring a stale surface never
  turns into "conversation absent": unless the tab is positively another run's (its text
  carries a foreign marker), the scan ends inconclusive (exit 7, no cooldown write) so a paid
  review hidden behind a rate limit keeps its recovery budget. Sightings are one atomic record
  each under `throttle.cooldown.seen.d/` next to the cooldown file
  (`PRO_GATE_THROTTLE_SEEN_DIR` overrides the path; records older than
  `PRO_GATE_THROTTLE_SEEN_TTL` milliseconds, default 7 days, or beyond 512 entries are
  pruned). Closes #208.
- The account-slot wait checks its deadline on the guard-failure path too, so a reservation
  guard that cannot be acquired ends in exit 7 at the deadline; the exit-7 message names which
  of the three waits expired. Closes #179.
- `pg_lock`'s no-flock branch bounds the reclaim-success spin the same way the reservation guard
  already does, without changing the on-disk pid/token shape. Closes #189.
- `--review-choice-selection` accepts a file that ends in exactly one newline (the natural
  output of `jq ... > file`); two newlines, leading whitespace, trailing prose and symlinks are
  still rejected, and each rejection now says why on stderr. Closes #203.
- A classic `--pr N --input connector` run with no `--diff` installs a connector-mode input
  binding instead of a full-pr merge proof for bytes the model never received. Bundle and
  both runs are unchanged. Closes #150.
- `install.sh` hashes the archive through stdin, so an `--archive` path containing a
  backslash verifies correctly instead of failing its own checksum. Closes #172.
- The last bare empty-array expansions in the engine and installer are guarded for bash
  older than 4.4 (stock macOS). The daemon was already guarded. Closes #176.
