## Highlights

- Looking up saved reviews now treats uppercase and lowercase GitHub repository names alike, so a spelling difference cannot hide a newer blocking review.

## Upgrade

Update the Pro-gate plugin and allow its normal runtime update to complete. Saved reviews need no migration.

## Details

The read-only facts query compares repository identities and marker prefixes case-insensitively during discovery and accepted-result matching. It preserves the original record bytes, file paths, digests, pull request numbers and completion ordering. Case-only edits without a matching accepted result digest remain invalid evidence; genuinely different repositories remain distinct.

Current-proof checks, review decisions, owner policies, the facts schema and public flags are unchanged. Fixes #267.
