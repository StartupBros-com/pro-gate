## Highlights

- Fixed a review-status check that could miss conflicting changes to the base branch in checkouts configured to fetch only selected branches.

## Upgrade

Update the marketplace plugin and install the matching runtime:

```sh
curl -fsSL https://raw.githubusercontent.com/StartupBros-com/pro-gate/v0.61.3/install.sh | bash -s -- --version 0.61.3
```

## Details

The optional GitHub adapter now fetches an explicit source/destination refspec before reading the base tip. Downstream integrations can reuse the exported `createGitBaseAccess` callbacks rather than reimplementing that pair. Existing comparison exports, flags, status rules and final rechecks are unchanged. Verification remains advisory and does not authorize a merge.

Tracked in [#270](https://github.com/StartupBros-com/pro-gate/issues/270); downstream owner integrations must adopt the shared helper separately.
