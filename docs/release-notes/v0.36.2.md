## Highlights

- Fixed a rare case where an interrupted review could get stuck alternating between restart and recovery instead of taking one stable next step.
- Recovery now consistently identifies the exact unresolved review without spending another review slot.

## Upgrade

Update the pro-gate plugin and install the matching v0.36.2 runtime. No action is needed for reviews that are already proceeding normally.

## Details

This release promotes the run-state stabilization already merged on the protected default branch. Public decisions and guarded dispatch checks now share one unresolved-review selector, including deterministic identity and terminal-artifact handling.

A previously interrupted review with no recoverable conversation or saved result remains blocked rather than spending another slot. Repairing that distinct terminal state requires the separately tracked no-conversation recovery path.
