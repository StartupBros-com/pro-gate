## Highlights

- Finished reviews no longer stay stuck behind a browser tab that still looks like it is thinking.
- `/pro-gate recover <PR-or-URL>` now finds and collects an already-started review without spending another Pro slot.
- Recovery now chooses the correct repository and newest review round, or asks for an exact run instead of guessing.

## Upgrade

Nothing to do — the next review picks it up automatically after the plugin and runtime update to v0.35.0.

## Details

ChatGPT can finish a review on the server while an older open tab still shows only the submitted prompt and thinking state. pro-gate now checks the canonical conversation in a disposable tab before deciding that the review is still running. The original tab is left untouched, and all existing run-marker, provenance, throttle, and reservation safeguards still apply.

That disposable tab is always closed again, including when the check runs out of time or the browser stops answering, so a slow or unresponsive browser no longer leaves stray ChatGPT tabs behind.

The new recovery action is strictly no-spend: it returns an already-saved review first and otherwise uses only the existing collection path for the selected run. It never launches a fresh review. Exact run markers remain available for expert recovery, while PR URLs and repository-scoped PR numbers select the newest charged run only when repository identity and ordering are unambiguous.
