## Highlights

- Older run-meta-only reviews now enter bounded recovery automatically instead of remaining unknown forever.
- Recovery keeps the original charged round and never needs manual state deletion.
- New v0.37 lifecycle behavior is unchanged.

## Upgrade

Update the plugin and runtime together to v0.37.1. No state migration or manual cleanup is required.

## Details

Version 0.37.0 terminalizes new proof-backed failures, but historical releases could leave canonical run metadata after their reservation disappeared. That state identified the charged attempt but had no miss counter, so exact recovery could never reach the existing TTL-plus-confirmed-miss terminal rule.

Version 0.37.1 reconstructs the missing reservation only from validated canonical run metadata. It preserves the exact round key, output path, charged epoch, and conservative original creation time; it invents no slot, model, round, or refund. One no-spend recovery invocation performs the existing spaced exact-marker probes. Live, complete, throttled, or inconclusive evidence remains fail-closed. Only an attempt already past TTL plus the configured confirmed-miss threshold becomes charged `recovery-exhausted` and eligible for a fresh typed decision.
