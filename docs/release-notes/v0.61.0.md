## Highlights

- Inspect saved reviews from your own scripts, including the reviewed revision, verdict and unresolved high-priority findings, without starting another review.
- Record and check exact-revision GitHub review statuses with an optional adapter included in Pro-gate; no private repository is required.
- Distinguish a valid older review from approval of your current changes, without treating missing or corrupt evidence as a clean result.

## Upgrade

Update the Pro-gate plugin and allow its normal runtime update to complete. Existing review commands remain available. The new inspection command and GitHub adapter are optional; they do not grant permission to merge or change your repository's rules.

## Details

The public `--review-facts --repo <checkout> --pr <number-or-URL> --json` command reports accepted artifact identity, digest, reviewed revision, verdict, named choices and unresolved P0/P1 counts. Current applicability is true, false or unknown, depending on the supplied proof. Inspection does not submit, collect or repair reviews, update quota state, or override a stop.

The installed `record-pro-gate-verdict.mjs` adapter requires Node.js and authenticated `gh`. Its recording flags are assertions checked against public review facts: only a current, choice-free SHIP can produce a successful status. Verification preserves exact-head and base-identity checks, including overlap checks after base advancement. Repository-specific exceptions and merge execution remain the caller's responsibility.

Artifact integrity does not establish the quality of a model's review. This release does not fix truncated or template-only answers, change continuation policy, or expand automatic merge authority.
