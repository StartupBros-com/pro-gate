## Highlights

- A bare verdict skeleton no longer counts as a completed review: Pro-gate requires a reference to the reviewed change before reporting success.

## Upgrade

Update the Pro-gate plugin and allow its normal runtime update to complete. Consumers can version-gate the new outcome and ledger fields on v0.62.0.

## Details

Reviews that name no path or shaped identifier from the reviewed diff fail with exit 6 and the typed outcome `template-verdict`. The classifier excludes severity labels and the verdict line, and plain English words cannot establish a match. A compact token index preserves the reviewed payload's vocabulary for later collection without another network fetch.

The browser harvester keeps waiting within its existing budget when the answer contains only a verdict block. Every run ledger row includes `body_bytes` and the boolean `names_nothing`; existing fields remain available. Fixes #262.

Saved results without retained diff vocabulary or a legacy path manifest cannot be revalidated automatically during collection. Their stored bytes remain available for inspection.
