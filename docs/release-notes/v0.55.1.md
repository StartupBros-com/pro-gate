# v0.55.1

## Highlights

- When Chrome stops answering, a review check or cleanup now finishes within its own time limit and reports that the browser was unreachable, instead of hanging until it is killed.
- Cleanup only counts a tab as closed when Chrome confirms it closed.

## Upgrade

Update the plugin and runtime together to v0.55.1. Nothing else to do. No browser restart or account change is needed.

## Details

The helper that finds, reads and tidies review conversations talks to Chrome over its local DevTools port. Most of those requests had no time limit. When Chrome was alive enough to accept a connection but not to answer it, which is common when the machine is short on memory, the request waited forever. The runtime's outer timer then killed the helper outright. That skipped the helper's own cleanup and left no record of what it had seen.

Every request to Chrome now has a limit. Requests made while a review is being looked for share that look's time limit. Requests that deliberately run after it get a few seconds of their own: closing tabs, re-checking a conversation before renaming or archiving it, and the final check that a review is still running. A request that times out is treated like any other unreachable browser: the result is "unknown", never "the review is gone", so a paid review is never given up because of it. The retry pause after a failed listing also no longer runs past the time limit.

Two cleanup paths used to count a tab as closed whenever they asked Chrome to close it. They now count only closes Chrome confirmed.

## Fixed

- Chrome DevTools requests that were never answered could hang review lookup, recovery and tab cleanup until the helper was killed (#224).
- The retry pause after a failed tab listing could run up to 30 seconds past a short check's time limit (#224).
- Idle-tab and post-review cleanup reported unanswered closes as closed (#224).
