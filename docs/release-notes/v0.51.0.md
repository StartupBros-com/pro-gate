# v0.51.0

## Highlights

- You can keep text review bundles inline instead of uploading them when attachment delivery is unreliable.
- Automatic file delivery remains the default; existing review input and recovery rules are unchanged.

## Upgrade

No configuration change is required to keep the existing behavior. To opt a review into inline
text delivery, set `PRO_GATE_BROWSER_ATTACHMENTS=never` in its environment or the runtime's
configuration file. Leave it unset to keep automatic delivery.

## Details

Pro-gate now forwards `PRO_GATE_BROWSER_ATTACHMENTS` to Oracle's `--browser-attachments` option:

- `auto` (default, also used for an empty value): Oracle chooses inline delivery or upload.
- `never`: Oracle requires inline-compatible text files and keeps their content inline.
- `always`: Oracle uploads file inputs.

This exposes an existing Oracle option; it does not raise browser limits, guarantee receipt by the
model, or enable connector access. It also does not change the selected review input policy.

Invalid values are rejected before a new review is charged. Status, recovery, and harvest remain
available even when this fresh-review setting is invalid.

The override provides a way to avoid upload delivery when it fails on a deployment. The underlying
upload failure and end-to-end delivery verification are not repaired by this change.
