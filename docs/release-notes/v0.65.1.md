## Highlights

- Pro's clean reviews stop being thrown away because the review prompt showed the wrong ending.
- The prompt's example verdict now matches the format reviews are accepted in, with the reason before the run marker.

## Upgrade

Update the Pro-gate plugin and its matching runtime. Nothing else to do.

## Details

The review prompt asked for a final line of `VERDICT: <verdict> — <reason>`, then showed an example ending in `VERDICT: <your verdict> (run marker: …)` with no reason. Pro sometimes reconciled the two by putting the reason inside the marker's parentheses: `VERDICT: SHIP (no actionable defects; run marker: …)`. The engine only accepts the marker in its own parentheses, so a finished SHIP review could not be bound to its run and was refused. Six such reviews were refused between 2026-10-13 and 2026-10-17 (#271).

The example now shows the reason before the marker and says never to put the reason inside the marker's parentheses. Marker acceptance is unchanged: the engine accepts exactly the shape the prompt now asks for, and nothing it refused before is accepted now.
