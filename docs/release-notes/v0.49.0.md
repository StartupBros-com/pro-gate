# v0.49.0

## Highlights

- A review whose prompt never reached ChatGPT at all now gives its slot back within minutes instead of holding one for six hours.
- Pro-gate says plainly when there is nothing to recover, so you are not told to go looking for a conversation that was never created.
- A review that did start and then became hard to reach is untouched by this: it is still kept, still collectable, and still nothing is thrown away on a guess.

## Upgrade

Nothing to do — the next review picks it up automatically. A run already stuck in this state
clears itself on the next few checks rather than waiting out its old six-hour window.

## Details

Sending a review to ChatGPT can fail in the browser before the prompt ever lands in a
conversation. When that happened, pro-gate could not prove the prompt had stayed unsent, so it
kept the attempt as recoverable and held one of the machine's shared review slots — for the full
six-hour window, because the only thing that could release it earlier was finding the
conversation, and there was never a conversation to find. Four such attempts in a row held every
slot on one machine at once, and no pull request anywhere on it could start a review.

- **An attempt that never produced a conversation is now allowed to end.** After the same bounded,
  spaced re-checks every other attempt goes through, an attempt for which no conversation was ever
  seen — not on this check, and not at any earlier point in its life — releases its slot without
  waiting out the rest of the window. Its review round stays spent: nothing here claims the prompt
  was never sent, only that it never reached a conversation, and no refund is made on that basis.
- **A review that does exist is deliberately not covered.** The rule only applies when pro-gate has
  never recorded a conversation for the attempt. If one was ever remembered, or was found carrying
  another review's answer, or produced text that could not be matched to this run, the attempt
  keeps the old, slower treatment and is still held for collection. Nothing is released on age, on
  a quiet page, or on a missing browser tab.
- **"Never seen" now means never seen, not merely no longer on file.** Two things could previously
  erase every trace of a conversation pro-gate had in fact found: deciding a page belonged to a
  different review, which forgets the address and stops looking at it, and meeting a rate-limit
  notice over the review's own page, which reports it as alive before anything is written down.
  Afterwards the attempt looked identical to one that never reached a conversation at all.
  Pro-gate now records each sighting the moment it happens and keeps that record for the life of
  the recovery, so a review that was genuinely found is never mistaken for one that never existed.
- **Left-over evidence is now attributed to the review that produced it.** Rejected text set aside
  for inspection is named after the attempt that wrote it. Reusing the same output file for a later
  review no longer lets one round's leftovers hold the next round's slot.
- **Reviews already running when you upgrade keep the old, slower treatment.** Pro-gate only ends
  an attempt early when it was recording sightings for that attempt's whole life. Anything already
  in flight at upgrade time predates that record, so its silence proves nothing and it waits out
  the full window as before. This settles itself within one window of upgrading, after which every
  review qualifies; if the record of when it started is ever missing, pro-gate assumes the older
  treatment rather than the faster one.
- **The status output says which of the two applies.** Where it used to tell you to wait out the
  window in every case, it now distinguishes an attempt that can still be collected from one that
  never had anything to collect, and says the slot is free once it is. It draws that distinction by
  asking the same rule that decides the release, so what status tells you and what pro-gate
  actually does cannot disagree.
