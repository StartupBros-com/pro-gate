## Highlights

- Corrupt saved-review metadata can no longer hide or demote a newer blocking review in `--review-facts` queries.
- Facts inspection no longer executes the inspected data root's `.env` or uses its `lib.sh` as a fallback, including when the command's arguments are invalid.
- Leftover numeric publication files such as `.tmp.456` no longer obstruct valid saved reviews; literal names such as `.tmp.v2` remain eligible.

## Upgrade

Update the Pro-gate plugin and allow its normal runtime update to complete. Normal review and recovery commands retain `.env` support. Facts queries use the library shipped with the command and accept existing exported configuration variables; they do not load defaults from the inspected data root.

## Details

Candidate selection checks the input binding against its accepted result digest before using the input's target to exclude a record or its charged epoch to order it. A valid run sidecar can still establish target and ordering. Relevant records with unproved ordering obstruct older favorable evidence, and a surviving valid result with an unknown target is not silently discarded. Digest-bound foreign records and valid foreign sidecars still disambiguate unrelated reviews.

The public facts schema and flags are unchanged. Named choices remain reported for downstream policy, and this patch does not change owner merge rules or claim that artifact integrity proves review quality. Fixes #265.
